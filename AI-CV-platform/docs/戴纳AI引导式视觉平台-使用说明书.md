# 戴纳 AI 引导式视觉平台

**使用说明书**

版本：v0.3.0-mvp  
文档日期：2026-08-26  
适用对象：视觉工程师、现场操作员、项目负责人

---

## 1. 产品概述

### 1.1 定位

戴纳 AI 引导式视觉平台是一套面向工业检测与科研视觉的全栈软件：用一句话描述检测需求，平台自动诊断成像质量、推荐算法路线并生成可视化流程图。工程师在节点画布上微调参数、批量验证漏检与误报，发布后操作员只看到少数业务参数和 OK / NG 结果。

平台把「传统图像算法」与「深度学习分类」放在同一条流程里，既适合污渍、计数、尺寸这类规则可写清的任务，也适合袋装物料种类识别这类需要模型判型的任务。

### 1.2 解决什么问题

| 现场痛点 | 平台做法 |
| --- | --- |
| 算法工程师写脚本、现场改不了 | 节点画布可视化调参，参数分工程师 / 业务 / 锁定三级 |
| 需求说不清、方案从零搭 | AI 助手做意图识别 + 成像诊断 + 可运行方案生成 |
| 调参靠感觉、不知道漏检误报 | 批量测试给出准确率、精确率、召回率、F1、漏检、误报 |
| 模型训完接不上产线界面 | 训练后导出 ONNX，接到流程的「AI 分类」节点即可发布 |
| 操作员容易改坏阈值 | 发布时只暴露业务参数，服务端按范围夹紧 |

### 1.3 适用对象

- **视觉 / 算法工程师**：搭流程、训模型、调参、发布版本。
- **现场操作员**：在运行页做单次或连续检测，只改允许的业务阈值。
- **质量 / 项目负责人**：看监控页的良率、置信度、耗时和逐次判定。

### 1.4 能力一览

- 项目管理：新建 / 复制 / 删除，流程版本与发布回滚。
- 数据管理：本地上传、服务器目录导入、train / val / test 划分。
- 在线标注：整图分类、矩形框、多边形、点；导出 COCO / YOLO / 分类清单。
- 成像诊断：曝光、对比度、清晰度、噪声、均匀性、纹理能量。
- AI 助手：自然语言生成检测流程；未配置大模型时走内置规则引擎。
- 节点流程：66 个算子，DAG 执行、结果缓存、逐节点预览。
- 分类模型：LBP + SVM（小样本）、EfficientNet-B0、YOLO 分类（需 GPU 依赖）。
- 批量测试：混淆矩阵指标、调参建议、误判样本回流训练集。
- 运行界面：数据集回放或模拟相机，业务参数 + OK/NG + 良率。
- 监控：设备在线、推理量、置信度分布、平均 / P95 耗时、逐次明细。
- 设备：模拟相机可连接采图；工业相机 / PLC / MES / 机器人为接口预留。

### 1.5 工作闭环

```
需求描述 → AI 助手（意图 + 成像诊断 + 方案）
                ↓
数据集 / 标注 → 节点流程（66 算子，DAG + 缓存 + 预览）
                ├─ 批量测试（良率 / 漏检 / 误报 / 误判回流）
                ├─ 模型训练（LBP+SVM / EfficientNet / YOLO-cls）
                └─ 发布版本 → 运行页（操作员：业务参数 + OK/NG）
                                    ↓
                              监控页（设备 · 置信度 · 耗时 · 明细）
```

## 2. 安装与启动

### 2.1 环境要求

- 操作系统：Linux（当前部署环境）或同等 Python 3.10+ 环境。
- 后端：Python 3.10，虚拟环境 `.venv`。
- 前端：Node.js + npm（Vite 开发服务器，默认端口 5173）。
- 可选 GPU：训练 EfficientNet / YOLO 分类时建议安装 PyTorch 与 Ultralytics。
- 存储：项目图片、预览缓存、模型文件和 SQLite 数据库均落在仓库 `data/` 目录。

### 2.2 快速启动

在仓库根目录执行：

```bash
cd /opt/AI-CV-platform

# 1) 后端依赖
python3 -m venv .venv && .venv/bin/pip install -r backend/requirements.txt

# 2) 前端依赖
cd frontend && npm install && cd ..

# 3) 演示项目（可选）
scripts/seed.sh                 # iPSC 克隆 + 合成布面污渍
scripts/seed_samples.sh         # 导入 sample_projects/ 示例（如密封袋谷物分类）

# 4) 同时启动后端 + 前端
scripts/dev.sh
```

### 2.3 访问地址

| 入口 | 地址 |
| --- | --- |
| 软件界面 | http://127.0.0.1:5173 |
| 后端 API 文档 | http://127.0.0.1:8000/docs |

`scripts/dev.sh` 可带端口参数：`scripts/dev.sh 8000 5173`。

### 2.4 大模型（可选）

把 `backend/.env.example` 复制到仓库根目录并改名为 `.env`，填写 `AICV_LLM_API_KEY`。配置后，顶栏会显示当前 LLM 型号；**不填也能用**，此时 AI 助手走内置规则引擎，适合离线现场。

### 2.5 自检

```bash
scripts/check.sh
```

覆盖接口契约、端到端冒烟、前端类型检查与首屏渲染。

## 3. 界面与角色

### 3.1 顶栏

- **项目**：进入项目列表（首页）。
- **监控**：全平台已部署方案的运行情况。
- **设备**：相机与外设连接、采图入库。
- **LLM 状态**：已配置大模型，或「LLM 未配置 · 规则引擎」。
- **模式开关**：工程师模式 / 操作员模式。

### 3.2 两种工作模式

| | 工程师模式 | 操作员模式 |
| --- | --- | --- |
| 面向谁 | 搭方案、调参、训模型的人 | 产线或实验室日常检测的人 |
| 能改什么 | 全部节点参数（含工程师级） | 仅发布时标记为「业务」的参数 |
| 主要页面 | 数据、AI 助手、流程、批量、模型、发布 | 运行页（OK/NG、良率、报警） |
| 保护机制 | 画布类型校验、缓存重算 | 服务端按参数范围夹紧，改不坏方案 |

切换开关在顶栏右侧。建议：调方案时保持工程师模式；方案发布后再切到操作员模式做验收演示。

### 3.3 项目内导航

进入某个项目后，左侧为：

| 页签 | 作用 |
| --- | --- |
| 数据 | 导入图片、划分、标注、直方图与成像诊断 |
| AI 助手 | 用自然语言生成 / 解释检测流程 |
| 流程 | 节点画布：搭图、改参、逐节点预览 |
| 批量测试 | 整批跑图，看漏检误报与调参建议 |
| 模型 | 训练分类器并管理模型库 |
| 运行 | 发布后的操作员界面 |

项目顶栏显示名称、任务类型、图片数 / 节点数 / 标注数、流程错误数、是否已发布。右侧 **发布** 会锁定当前流程为新版本。

## 4. 项目管理

一个项目 = 一套检测方案：数据集 + 视觉流程 + 标注 + 发布版本。

### 4.1 新建

1. 首页点击 **新建项目**。
2. 填写项目名称。
3. 用一句话写清检测需求（会带入 AI 助手）。
4. 选择起始模板（可后续被 AI 方案覆盖）。
5. 填写标注类别（如 `OK, NG` 或 `玉米, 稻谷, 小麦`）。

内置模板：

| 模板 | 适用 |
| --- | --- |
| 空白项目 | 从零搭建 |
| iPSC 克隆定位 | 显微纹理定位克隆、面积占比判定 |
| 表面污渍 / 瑕疵检测 | CLAHE + 自适应阈值 + Blob |
| 目标计数 | Otsu 分割后统计数量 |
| 尺寸测量 | 分割后测主轴长度并按公差判定 |
| 无监督异常检测 | 仅用正常样本，残差定位异常区域 |

### 4.2 打开、复制、删除

- 点击卡片进入该项目的数据页。
- 悬停卡片可 **复制**（完整拷贝方案）或 **删除**（图片、标注、运行记录一并删除，不可恢复）。
- 搜索框按名称过滤项目。

## 5. 数据与标注

### 5.1 导入图片

- **本地上传**：选择一张或多张图片。
- **服务器目录导入**：填写本机路径，可选递归扫描子目录。适合已经按类别文件夹整理好的数据集（如 `data/train/玉米/`）。

导入后可按划分（未分配 / 训练 / 验证 / 测试）、类别、是否已标注筛选，并支持关键字搜索。

### 5.2 划分数据集

选中若干缩略图后，可批量改划分。训练分类模型时：

- 留空划分 = 使用全部已标注图。
- 指定 `train,val` = 只使用这些划分中的样本。

建议：分类任务按类别文件夹导入后，再按约 8:2 划分训练 / 验证。

### 5.3 标注

图像查看器支持缩放、平移、像素探针。工具栏：

| 工具 | 用途 |
| --- | --- |
| 浏览 | 平移缩放，不新增图形 |
| 矩形框 | 缺陷、目标框 |
| 多边形 | 不规则区域 |
| 打点 | 关键点 / 位置 |

还可给整图打分类标签（如「玉米」），并写备注。右侧三个页签：

- **标注**：当前图的类别、图形、备注。
- **质量**：直方图 + 成像诊断（曝光 / 对比度 / 清晰度 / 噪声 / 均匀性）。
- **统计**：数据集规模、类别分布、划分情况。

标注可导出 **COCO**、**YOLO**、**分类清单**，也可从这三种格式按文件名回导。

### 5.4 成像诊断怎么读

诊断结果会标出偏暗、过曝、对比不足、模糊、噪声偏高等问题。这些结论会进入 AI 助手的方案规划：例如对比不足会倾向加 CLAHE，纹理任务会倾向局部标准差算子。**先保证成像合格，再调算法**，往往比盲目加节点更有效。

## 6. AI 助手

### 6.1 生成方案

1. 进入 **AI 助手**，需求框里用业务语言描述目标（可先选一张代表图）。
2. 可单独点 **成像诊断**，或直接 **生成方案**。
3. 查看识别出的任务类型、推荐路线、节点说明。
4. 确认后点 **应用到流程**，自动跳转到流程页。

示例说法：

- 「检查布面上的深色污渍，超过 500 像素算 NG」
- 「统计视野内的圆形颗粒数量，少于 20 个报警」
- 「显微图像里找出纹理致密的克隆区域，面积占比低于 10% 报警」
- 「判断零件是否装配到位」
- 「根据袋装谷物照片判断是玉米、稻谷还是小麦」

写需求时尽量带上：**看什么、怎样算不合格、有没有数量或尺寸门槛**。

### 6.2 追问与解释

下方对话可继续问「这个阈值为什么是 500」「漏检多了该改哪」。历史记录按项目保存。

### 6.3 安全机制

AI 只能使用注册表里的白名单算子。生成图会做端口类型与参数范围校验；不合法的图会退回规则引擎方案，因此界面上拿到的永远是能跑的流程。未配置 API Key 时同样可用，只是方案更偏模板。

## 7. 视觉流程

流程页是工程师的主战场：左侧算子库，中间画布，右侧属性与结果。

### 7.1 画布操作

- 从左侧把算子拖到画布，或点击添加。
- 端口按类型着色：图像、掩膜、ROI、区域、数值、判定。类型不兼容的连线会被拒绝。
- 选中节点后，右侧改参数；开启自动运行时，改参会重跑下游。
- 节点上会显示耗时；命中缓存时标 `cache`（只改后段时前段不重算）。
- 可「只执行到此节点」，便于分段试参。
- ROI 节点支持在预览图上框选，坐标回填到参数。

### 7.2 参数分级

每个参数有级别：

- **engineer**：仅工程师模式可见。
- **business**：发布后暴露给操作员，且有范围限制。
- **locked**：锁定，界面不可改。

判定类参数（最小面积、数量上限、OK 类别、最低置信度）通常应标成业务参数，方便现场微调而不开放整条算法链。

### 7.3 预览与结果

执行后可逐节点看中间图（原图、掩膜叠色、轮廓、OK/NG 标注）、日志和测量值。流程存在类型错误或环时，项目顶栏会提示错误数，**应先修好再发布**。

### 7.4 版本

流程自动保存。历史版本可查看与回滚。点 **发布** 会生成新版本号，并把当前业务参数集合同步到运行页。

## 8. 批量测试

用来回答：「这套方案在这一批图上到底准不准？」

1. 选择划分（可留空=全部）和最多张数。
2. 指定哪些标注算 NG（默认 `NG`；分类任务可填不合格类别名）。
3. 开始运行。完成后查看：

   - 准确率 / 精确率 / 召回率 / F1
   - TP（正确报警）、TN（正确放行）、FP（误报）、FN（漏检）
   - 平台给出的调参建议
   - 逐张结果；点开可看原图与判定原因

4. 误判样本可一键回流训练集，回到数据页补标或改标后再训。
5. 结果可导出 CSV。

没有标注时仍能跑通流程、看判定分布，但混淆矩阵指标会缺失。建议至少标几十张代表性样本再谈「能不能上线」。

## 9. 模型训练

模型页训练**图像分类**模型，训完出现在模型库，供流程里的 **Classification（AI 分类）** 节点调用。

### 9.1 样本要求

- 至少 2 个类别、4 张已标注图（经典方法）。
- 深度模型建议每类更多样本（平台下限约 8 张，实际建议每类 20 张以上）。
- 样本来自整图分类标签，或框标注裁切。

页面会显示可用样本数、类别分布、各划分数量。

### 9.2 三种架构

| 架构 | 特点 | 何时选用 |
| --- | --- | --- |
| LBP + SVM | 纹理特征，无需 GPU，几十张即可 | 显微纹理、表面纹理分型 |
| EfficientNet-B0 | 通用外观分类，导出 ONNX | 袋装物料、产品外观种类 |
| YOLO 分类 | Ultralytics YOLO-cls（默认 yolo11n-cls） | 需要较快迭代或已有 YOLO 习惯时 |

深度架构需安装 PyTorch（及 YOLO 时的 Ultralytics）。未安装时选项旁会提示「未安装依赖」，平台其余功能不受影响。

### 9.3 训练参数

- **LBP+SVM**：核函数（rbf / linear / poly）、惩罚系数 C。
- **深度模型**：轮数、输入边长、batch；YOLO 还可选 n / s / m 底座。
- **参与训练的划分**：如 `train,val`；留空则用全部已标注图。

开始训练后请等待完成提示。成功后卡片上会列出类别、框架、输入尺寸和验证准确率等指标。

### 9.4 接到流程

1. 流程中加入 **Classification** 节点。
2. 参数「模型」填写模型库中的 ID。
3. **OK 类别**：逗号分隔；命中这些类别且置信度达标则 OK。留空表示只输出类别、全部当 OK。
4. **最低置信度**：低于该值判 NG，便于低把握样本人工复核。

权重若为 `.pt`，推理时会自动改用同名 `.onnx`。检测 / 分割训练节点目前为接口预留，分类是当前可训练的任务。

## 10. 发布与运行

### 10.1 发布

1. 确认流程无错误、批量指标可接受。
2. 项目顶栏点 **发布**，填写版本说明（例如「最小面积改为 800 px」）。
3. 发布后顶栏显示「已发布」。新发布会刷新运行页的业务参数默认值。

### 10.2 运行页（操作员）

未发布时运行页不可用。发布后可以：

- **单次触发**：对当前图跑一遍，看 OK/NG、原因、测量值、耗时。
- **连续检测**：按间隔回放数据集，或使用已连接的模拟相机。
- **业务参数**：只出现发布时标记为 business 的项（面积阈值、OK 类别、置信度等）。
- **良率**：连续运行时的 OK 比例与报警。

建议操作员只改业务参数做现场微调；算法结构回工程师模式在流程页修改，再发新版。

## 11. 监控

顶栏 **监控** 聚合全平台已部署方案（不限于当前项目）。

可看：

- 时间窗口：1 小时 / 6 小时 / 24 小时 / 7 天
- 设备在线 / 离线与各自推理量
- 模型平均置信度与分布
- 平均耗时、P95 耗时
- 良率趋势（OK / NG / 错误）
- 逐次预测明细：点一行可看原图、测量值、判定原因

点设备、模型或项目行可筛选明细。也可只看低置信度记录，便于抽检不稳样本。

说明：每个运行会话只保留最近约 200 条推理；「7 天」窗口实际是这 200 条里落在窗口内的部分。服务重启后设备状态回到离线，需在设备页重新连接。

## 12. 设备

设备页列出已注册适配器。

- **模拟相机**：可连接、断开、采图。采图时可指定项目，图像直接入库。
- **工业相机、PLC、MES、机器人**：界面标注「接口预留」，调用返回未实现（HTTP 501）。

运行页连续检测可选「相机」源，使用已实现且已连接的设备。对接真实相机时，在后端实现 `DeviceAdapter` 的 `connect` / `grab` 并注册即可，无需改前端。

## 13. 推荐作业流程

### 13.1 五分钟演示（表面污渍）

1. 打开示例项目「白布污渍检测」。
2. 数据页浏览缩略图，打开质量页看直方图与诊断。
3. AI 助手输入「检查布面上的深色污渍，超过 500 像素算 NG」→ 生成 → 应用到流程。
4. 流程页逐节点看中间图，把最小面积等参数标成业务参数。
5. 批量测试跑一批，确认漏检 / 误报。
6. 发布 → 运行页单次或连续检测。
7. 打开监控看推理量与明细。

### 13.2 分类任务（如密封袋谷物）

1. 新建项目，类别填 `玉米, 稻谷, 小麦`（按实际种类）。
2. 按类别文件夹导入图片，划分 train / val。
3. 给每张图打整图类别（若目录名即类别，导入后请核对标签）。
4. 模型页选 EfficientNet-B0 或 YOLO 分类，设置轮数与边长后训练。
5. 流程：图像输入 → AI 分类（填写模型 ID 与 OK 类别）→ OK/NG → 显示。
6. 批量测试用验证集看准确率；误判回流后可再训一版。
7. 发布给操作员：业务参数通常是「最低置信度」。

拍照建议（袋装物料）：哑光白底、袋子展平、两侧柔光、垂直俯拍、距离固定、粮面占画面七成以上。成像不一致往往比模型结构更能决定准确率。

### 13.3 iPSC 克隆

使用模板「iPSC 克隆定位」，或让 AI 助手按「找出纹理致密的克隆、统计面积占比」生成。领域算子包括克隆分割、克隆指标、LBP 特征；也可接「分块分类」做形态分型。先用数据页诊断确认显微图的对比与清晰度。

算子按类别出现在流程页左侧。名称以后端注册名为准，界面显示中英文标签。

| 类别 | 算子 | 说明 |

| Input | Image / Test Pattern / Camera（预留） | 读图、测试图、相机输入 |

| Feature | Canny、Sobel、Laplacian、轮廓、Blob、圆、直线、模板匹配 | 几何与边缘 |

## 15. 常见问题

**Q：生成方案按钮没有反应？**  
先填写非空需求。若后端未启动，顶栏会一直「连接中」。确认 `scripts/dev.sh` 两个端口都在监听。

**Q：没有 API Key，AI 助手能用吗？**  
能。走规则引擎，方案偏模板但仍可运行。配 Key 后解释与任务理解会更贴需求。

**Q：YOLO / EfficientNet 是灰的？**  
后端未安装 `torch` / `torchvision`（以及 YOLO 所需的 `ultralytics`）。装好后刷新模型页即可。LBP+SVM 始终可用。

**Q：训练报样本不足？**  
至少两个类别且有足够已标注图。检查划分过滤是否把样本滤空；划分输入留空即用全部标注。

**Q：运行页提示未发布？**  
先在项目顶栏发布。流程有错误时仍能发布，但运行会失败，请先在流程页修错。

**Q：改了流程，操作员界面没变？**  
运行页绑定的是已发布版本。改完需再次发布。新版本会重置该项目运行会话的业务参数默认值。

**Q：监控里设备全是离线？**  
设备状态在 API 进程内存中。重启后端后需到设备页重新连接。

**Q：批量指标全是空的？**  
图没有标注，或 NG 类别名与标注不一致（例如标的是「不合格」却在批量页填 `NG`）。

**Q：预览图和原图不一致？**  
大图会生成边长受限的预览用于流程（原文件仍保留）。极端小目标请确认预览分辨率是否够用。

## 16. 部署边界与后续

当前版本适合**单机单工位**现场或实验室：

- 采集以模拟相机为主；硬件触发、多相机同步、实时节拍未验证。
- 批量与运行使用进程内线程池，不是多机任务队列。
- SQLite + 本地文件；高并发写入需迁移 PostgreSQL 与对象存储。
- 监控不做长期时序存储。
- 深度学习目前覆盖**分类训练与 ONNX 推理**；检测 / 分割训练、多工位编排、权限审计为后续能力。
